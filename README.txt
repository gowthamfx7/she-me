Purna Birthday Website
=======================

1. Extract the ZIP.
2. Open index.html in Chrome/Edge/Safari.
3. Tap "Open My Heart" so the birthday song can start (mobile browsers may block audio autoplay until a tap).
4. The song is set to loop.
5. The countdown targets 16 October 2026.

Files:
- index.html
- assets/purna.jpg
- assets/birthday-song.m4a
